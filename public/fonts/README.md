# Fonts

Add the Humane variable font here as `Humane-Variable.woff2`.

1. Download Humane from the designer's official page and confirm the license allows commercial web use.
2. Convert to WOFF2 if needed and save it here with that exact file name.

Until the file exists, the site falls back to Arial Narrow / Sora for display text.
Sora (body/UI) loads automatically through `next/font/google`.
